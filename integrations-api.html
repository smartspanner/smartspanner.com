Frequently Asked Questions

What data can I access through the API?

The Smartspanner API provides access to assets, work orders, preventive maintenance schedules, inventory, and more. You can pull data for reporting, integrate with external systems, or build custom workflows.

Can I connect Smartspanner to Power BI?

Yes — our REST API allows you to stream maintenance data directly into Power BI to create real-time, interactive dashboards tailored to your business needs.

Is the API secure?

Yes — the API uses token-based authentication with secure API keys. All data is transmitted over HTTPS on our secure cloud infrastructure.

Do I need a developer to use the API?

The API is designed to be straightforward and well-documented. Many integrations — especially Power BI connections — can be set up without deep development expertise. Our team is also available to help.

Which plans include API access?

API access is available on Standard and Advanced plans. Contact our team for details on getting started with integrations.
