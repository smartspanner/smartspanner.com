Multi-Site CMMS Questions

Can users be limited to particular sites?

Yes. Site-based permissions control which locations a user can access and see. A user can be given access to one site, several selected sites or wider organisation-level visibility as required.

Can different sites use different currencies?

Yes. Sites can use their configured currency. For organisation-wide Inventory Performance, site values are converted into the Company Profile base currency so locations in different countries can be compared consistently.

Does Smartspanner support multiple languages?

Yes. The app interface supports English, German, French, Spanish, Portuguese, Lithuanian, Thai, Malay and Japanese. Supported procedures, checklists, instructions, descriptions and comments can also be translated in the app.

Can we compare maintenance KPIs between sites?

Yes. Most Performance KPI views include site breakdowns or rankings, and the same area can be filtered to an individual site and date range for local analysis.

Do we need a separate Smartspanner account for every site?

No. Multiple sites are managed within the same organisation account, allowing local site working and organisation-wide reporting without maintaining disconnected systems.
